# Netflix Clone

A responsive Netflix-style homepage built using HTML and CSS.

## Features

- **Modern UI:** Styled to resemble Netflix with a sleek design.
- **Responsive Layout:** Works across different screen sizes.
- **CSS Effects:** Includes hover effects and animations.

## Technologies Used

- HTML5
- CSS3

## Future Improvements

- Adding JavaScript for interactive features.
- Implementing user authentication and movie database integration.
